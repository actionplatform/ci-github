# ci-github

Composite GitHub Actions for projects generated by `action-platform`. Logic lives in [ci-scripts](https://github.com/actionplatform/ci-scripts); each action fetches the scripts at `v1` and runs them.

| Action | Does |
|--------|------|
| `actionplatform/ci-github/setup@v1` | toolchain (`setup-python`, `setup-go`, …) + dependencies, language from `platform.toml` |
| `actionplatform/ci-github/check@v1` | lint, format, tests |
| `actionplatform/ci-github/release@v1` | `LAST_VERSION` + version constants from the tag, commit back |
| `actionplatform/ci-github/publish@v1` | build + publish a library for `registry` (the scope the platform deploys to); PyPI through trusted publishing unless `pypi-token` is given — the platform dispatches the workflow with `version` and `registry` |
| `actionplatform/ci-github/conventional-commit@v1` | Conventional Commits 1.0.0 on the PR range |
| `actionplatform/ci-github/gitflow@v1` | PR branch name and target follow git-flow |

```yaml
steps:
  - uses: actions/checkout@v4
  - uses: actionplatform/ci-github/setup@v1
  - uses: actionplatform/ci-github/check@v1
```

Tag `vX.Y.Z`; `v1` floats to the latest.
